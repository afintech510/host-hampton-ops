## 13. Platform-specific notes

- **The Bash / GigSalad:** create **two** listings where allowed — one as a *Party Venue*
  (studio) and one as *Mobile / Party Entertainment* (mobile arm). Lead with the mobile
  angle ("we bring the party to you") since that's the differentiator here.
- **Peerspace / This Open Space:** photo-quality-driven — use the best studio + party
  photos; list multiple categories (see §5 tip). Set an hourly rate (weekday vs weekend —
  see §9) and a minimum-hours if required.
- **Tagvenue / Eventective:** inquiry directories — completeness of the profile drives
  ranking. Fill every field; add the full service area (§7).
- **PartySlate:** portfolio-first — upload real event galleries (showers, first birthdays,
  themed parties). Treat as brand-building, not a fast-lead channel.
- **Nextdoor Business / Macaroni KID:** hyperlocal — emphasize Speonk/Westhampton and the
  mobile radius; lean on the woman-owned local angle.
- **Google Business Profile:** set the **mobile service-area** (not just the pin), add
  secondary categories (Children's Party Service, Party Planner, Event Venue), and post
  weekly. Highest-converting channel — optimize before adding new sites.
